# SEPTA Regional Rail Map Dark Theme

There exists a SEPTA regional rail map in a light theme. It is sold out and I thought of printing one myself but I wanted a dark mode
such as the one shown [here](https://shop.septa.org/collections/bathroom/products/navy-rail-map-shower-curtain)

I used this color scheme to guide changing the colors for the light mode version of the poster: [og poster](https://shop.septa.org/products/rrd-poster?_pos=10&_sid=e48d5052f&_ss=r)

My iteration grabbed the map from a separate pdf that is unfortunately square in aspect ratio but much higher resolution (14401x14401).
This resolution at 600dpi should result in a relatively crisp 24in x 24in poster.
